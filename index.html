Approach

How I test

Automated tools catch only part of the problems. I pair axe and WAVE scans with hands-on testing against the four WCAG principles.

  • P

    Perceivable

    Alt text, captions, color contrast and text that holds up at 200% zoom and in ZoomText.

  • O

    Operable

    Every control reachable by keyboard, a visible focus outline and no keyboard traps.

  • U

    Understandable

    Clear labels, helpful error messages and no surprise page changes.

  • R

    Robust

    Correct names, roles and states, so JAWS and NVDA announce every element correctly.
